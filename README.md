# Election Watch Hub

Prompt: Develop the Official Website for Yiaga Africa's Watching The Vote Initiative

Overview

Design and develop a modern, responsive, accessible, and highly professional website for Yiaga Africa's Watching The Vote (WTV) initiative.

The website should reflect transparency, election integrity, civic participation, democracy, data-driven election observation, and public trust.

The design should feel similar to international organizations such as:

 National Democratic Institute (NDI)

 International Foundation for Electoral Systems (IFES)

 Carter Center Election Observation

 European Union Election Observation Missions

 African Union Election Observation Missions

The visual style should be clean, minimal, modern, and trustworthy.

Primary colors should use Yiaga Africa branding:

 Blue

 White

 Dark Gray

 Light Gray

Accent colors:

 Green (positive)

 Orange (warning)

 Red (critical alerts)

Generate a complete production-ready project including:

 React + Vite + TypeScript architecture.

 Clean, scalable folder structure following feature-based organization.

 Fully responsive layouts for mobile, tablet, and desktop.

 Reusable UI component library.

 Mock API integration with realistic sample data.

 Accessible, WCAG AA-compliant components.

 Interactive maps, charts, and dashboards.

 Smooth animations using Framer Motion.

 Well-documented code with clear setup instructions and deployment guidance.

The final result should look and feel like the digital platform of a leading international election observation organization, emphasizing professionalism, transparency, credibility, and trust while showcasing Yiaga Africa's leadership in election observation and democratic governance across Nigeria.
